## v5 全局水彩蓝紫背景（用户：背景要水彩蓝紫，所有界面统一，要真水彩效果）
- 关键技术决策：CSS 渐变/模糊做不出水彩毛边（试过 blur 21–48px 的多层色斑，效果是「均匀色雾」，不像水彩）。改为 **SVG 滤镜生成底图** `design/watercolor-bg.svg`（1600×1000）：
  - `feTurbulence`（fractalNoise 0.006–0.009）+ `feDisplacementMap`（scale 130–170）把规则椭圆撕成有机扩散边 → 水彩毛边
  - `feGaussianBlur` 9–14 柔化；每个色块叠加低频噪声层（soft-light, opacity .10）→ 颜料云絮/浓淡不匀
  - 渐变停靠点在 85–90% 处二次加深 → 湿边颜料沉积
- 配色比例锁定 **水彩蓝 62% : 湿紫 26% : 浅青 12%**（蓝 rgb 92 126 204 / 紫 rgb 131 114 198 / 青 rgb 143 188 201），纸白 #FBF8F2。
- 三层结构：
  1. `#wc` 固定层 `position: fixed; inset: -2%`，`background: url(watercolor-bg.svg) center/cover`，150s 极慢 `scale(1→1.04)` 呼吸
  2. `.wc-veil` 中轴提亮绢（radial 56% 纸白），保正文对比度
  3. `section::before` 每屏复用同一张图，只改 background-position / scale，opacity .52，上下 mask 渐隐 26% 消除横向硬分界
- 卡片改半透明纸白 `--card-w: rgba(255,253,248,.90)` + backdrop blur；描边改淡水彩蓝 `rgb(var(--wc-blue-deep)/.13)`；三关封面与 CTA 面板用同一张 SVG 做 `mix-blend-mode: soft-light` 叠印，形成「同一张纸上画的」。

**工程教训（重要）**：`.rv` 原本是 `opacity:0` + IntersectionObserver 加 `.in`。凡观察器不触发 / 截图时序早于回调，元素就永久空白（本次首屏 IP 卡反复消失就是这个）。改为**渐进增强**：
```css
.rv { opacity: 1 } .rv.rv-wait { opacity: 0; transform: translateY(34px) }
.rv.rv-wait.in { opacity: 1; transform: none }
```
JS 只把「初始就在视口下方」的元素加 `.rv-wait` 并 observe。首屏元素、无 JS、观察器失效都不会空白。同类问题：`animation ... both` 会保留 `from` 状态，在动画不执行的环境下同样永久隐藏 —— 首屏主视觉（IP 卡）改用 `animation` 无 `both` + 显式 `opacity:1`。
